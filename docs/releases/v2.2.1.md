# Beyond Glimpse v2.2.1

Episode availability correction for the lazy TV browser.

- Episode tables now represent episodes actually present in Jellyfin rather than metadata-only placeholders.
- Jellyfin episode queries include `IsMissing=false`.
- Defensive filtering also rejects items marked `IsMissing`, `IsVirtualItem`, or `LocationType=Virtual`.
- Real STRM-backed episodes remain visible; no local-filesystem-path requirement is introduced.
- Existing episode caches are invalidated once on upgrade so previously cached virtual/missing placeholders cannot linger.
- The global 72k+ catalogue database, bootstrap, posters, library browsing, and lazy metadata architecture are unchanged.
