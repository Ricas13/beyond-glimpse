# Beyond Glimpse v2.1.0

Library-aware browsing for the Jellyfin catalogue service.

## Highlights

- Movies and TV Shows keep their existing all-content tabs and gain adjacent library dropdown controls.
- Each dropdown lists the eligible Jellyfin libraries for that media type with local catalogue item counts.
- Selecting a library scopes pagination, search, genre filters and sorting server-side in SQLite.
- Added `/api/libraries` plus optional `library=` filtering on `/api/items` and `/api/genres`.
- Library discovery is cached in the catalogue service for one hour by default, so opening the dropdown does not repeatedly query Jellyfin.
- No catalogue rebuild, artwork migration or rich-metadata crawl is required.
- PWA shell cache bumped so the new browse control is picked up promptly.

The feature preserves the v2 large-library model: browsers still receive only one bounded page of cards at a time and Jellyfin remains outside normal browse/search traffic.
