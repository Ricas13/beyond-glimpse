# Beyond Glimpse v2.2.0

Beyond Glimpse can now browse TV seasons and episodes directly inside a series modal without expanding the global catalogue sync.

## TV browsing

- Opening a TV series lazily fetches its season list.
- Season 1 is selected automatically when available.
- Selecting another season replaces the episode table in place.
- Episode rows show number, title, air date, runtime and a compact overview.
- Mobile layouts hide secondary date/runtime columns while preserving episode titles and summaries.

## Performance

- No seasons or episodes are added to the lightweight 72k-title catalogue bootstrap.
- Only the opened series receives a season request.
- Only the selected season receives an episode request.
- Season and episode payloads are cached persistently in SQLite for six hours by default (`EPISODE_CACHE_TTL_SECONDS=21600`).
- Browser promises also avoid duplicate requests during one page session.

## Security and resilience

- Series IDs must already exist as public TV entries in the Beyond Glimpse catalogue.
- Requested season IDs are checked against that series before any episode request is allowed.
- Stale cached season/episode data can be served when Jellyfin is temporarily unavailable.
- Rendering uses safe DOM APIs and `textContent`; no metadata is inserted with `innerHTML`.

No catalogue rebuild or schema reset is required when upgrading from v2.1.0.
