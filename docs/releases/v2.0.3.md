# Beyond Glimpse v2.0.3

This release fixes the browser-runtime injection bug that prevented the v2 catalogue frontend from executing even though the SQLite catalogue API was healthy.

## Fixed

- Runtime and startup script tags are now inserted before the real final `</body>` tag.
- Existing generated pages where the tags were accidentally placed inside Glimpse's HTML comment are repaired automatically.
- The browser runtime URL is bumped to `large-library.js?v=6` and startup helper to `startup-status.js?v=3`.
- The PWA shell cache is bumped to `beyond-glimpse-shell-v12`.
- Regression tests now reproduce the exact upstream Glimpse comment containing literal `</body>` text.

No catalogue schema or SQLite migration is involved. Existing indexed Jellyfin data is preserved.
