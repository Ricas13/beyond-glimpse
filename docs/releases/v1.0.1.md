# Beyond Glimpse v1.0.1

This patch release hardens first-time full catalogue imports against expensive Jellyfin 12 rich-metadata pages on very large libraries.

## Fixed

- Full rebuilds now start rich `/Items` requests at 100 items per page by default instead of inheriting the 500-item incremental page size.
- If Jellyfin times out reading a rich page, Beyond Glimpse retries the same offset with a smaller page (100 → 50 → 25) rather than abandoning the whole sync.
- Read timeouts are no longer retried three times with the identical oversized request, avoiding multi-minute stalls before adaptive fallback can happen.
- Connect failures and retryable HTTP status codes still retain retry/backoff protection.

## Configuration

A new optional setting is available:

```env
FULL_SYNC_PAGE_SIZE=100
```

`PAGE_SIZE=500` still controls ordinary incremental changed-metadata requests. The lightweight periodic ID inventory remains unchanged and continues to use large pages for efficiency.

This release does not change the public catalogue schema, so upgrading does not force a rebuild solely because of the version bump.
