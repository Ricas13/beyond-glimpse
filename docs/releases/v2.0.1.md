# Beyond Glimpse v2.0.1

Fixes the v2.0.0 root-page browser regression that could show **Failed to load movie data** even while the new Jellyfin catalogue API was healthy and actively indexing.

## Fixed

- Root-page Jellyfin detection no longer depends on upstream Glimpse using a server-prefixed static JSON path.
- The server-themed document title supplies a credential-free primary-server hint before the v2 browser runtime takes over.
- Plex and Emby retain their existing compatibility paths.
- The browser runtime URL is bumped to `large-library.js?v=4`.
- The PWA shell cache is bumped to `beyond-glimpse-shell-v10`, forcing mobile browsers to discard the broken v2.0.0 frontend asset.

No catalogue database migration or re-bootstrap is required. Existing v2 SQLite state is preserved across the upgrade.
