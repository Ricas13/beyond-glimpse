# Beyond Glimpse v2.0.2

Browser reliability and first-paint performance fix for Jellyfin catalogues.

- Removes the v2.0.1 function `toString()` server-detection shim.
- Detects the configured primary server directly from the credential-free themed document title generated by the entrypoint.
- Requests and renders the first paginated Jellyfin catalogue page before loading genre aggregation, so genre metadata cannot block first paint.
- Upgrades existing v2.0.1 generated pages in place and removes the legacy shim.
- Bumps the application shell cache and runtime query version so iOS/Safari clients discard the broken cached frontend.
- Preserves the existing SQLite catalogue; no re-bootstrap or migration is required.
