# Beyond Glimpse v1.0.0

The first production release of Beyond Glimpse turns the original Glimpse catalogue into a large-library-focused Jellyfin frontend designed to minimise storage, repeated API work and browser overhead.

## Highlights

- Jellyfin changed-only metadata sync with safe server-time watermarks.
- ID-only periodic deletion/move reconciliation instead of recurring full metadata rebuilds.
- No bulk Jellyfin poster downloads.
- Tag-versioned on-demand posters through Nginx with a hard 256 MiB ephemeral cache ceiling.
- Compact browse indexes plus lazy detail shards.
- Bounded 96-card desktop / 48-card mobile rendering and debounced search.
- Backdrops disabled by default.
- Traefik-first production compose with no direct host port exposure.
- Nginx/Docker/Traefik health checks and private sync telemetry.
- First catalogue import runs behind an already-live Nginx service, with a browser preparation state and automatic refresh.
- Public-web security headers and metadata-safe DOM rendering.
- Pinned Python runtime dependency and full Docker-build regression testing.
- Built-in live Jellyfin deployment smoke test and production acceptance checklist.

## Upgrade notes

The first Jellyfin sync after upgrading from original Glimpse or an older Beyond Glimpse catalogue may intentionally perform one full metadata reconciliation to migrate catalogue state. It does not bulk-download posters.

For the recommended Traefik deployment:

```bash
cp .env.traefik.example .env
# edit .env
docker compose -f docker-compose.traefik.yml up -d --build
```

After the first catalogue is ready:

```bash
docker exec beyond-glimpse python /app/scripts/smoke_test.py
```

See `README.md`, `CHANGELOG.md` and `docs/PRODUCTION_CHECKLIST.md` for complete details.
